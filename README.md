# Конспектор

Расширение для Google Chrome. Оно слушает видео в текущей вкладке, переводит речь в текст и складывает его в конспект в боковой панели. Сайт значения не имеет: YouTube, онлайн-курсы, вебинары, VK Видео и т. д.

## Установка (2 минуты)

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуйте архив.
2. В Chrome откройте `chrome://extensions`, справа вверху включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку **`extension`** из распакованного архива.
4. Закрепите значок «Конспектор» на панели (значок пазла → булавка).
5. Сразу откроются настройки. Получите бесплатный ключ на [console.groq.com/keys](https://console.groq.com/keys) (вход через Google, карта не нужна), вставьте его и нажмите **Сохранить**.

## Как пользоваться

1. Откройте видео и нажмите значок Конспектора → **● Начать запись этой вкладки** (или горячая клавиша **⌥⇧S** на Mac, **Alt+Shift+S** на Windows).
2. Откроется боковая панель. Через 15–30 секунд появится текст, а каждые 3–4 минуты конспект будет дописываться сам.
3. Вкладка **Расшифровка** показывает весь текст с таймкодами.
4. Внизу панели есть кнопки: **Итоги** (краткая выжимка всего видео), **Копировать**, **Копировать с промптом** (для ChatGPT / Claude), **Скачать .md**.

Все записи хранятся локально в браузере, их можно переключать в списке сверху.

**Пауза и скорость.** Конспектор находит видеоплеер на любом сайте, в том числе встроенный через iframe (курсы, VK, Vimeo и т. п.):
- поставили видео на паузу — недоговорённая фраза сразу расшифровывается, конспект дописывается, а запись ждёт продолжения в той же сессии;
- кнопки **1x / 1.25x / 1.5x / 2x** в панели меняют скорость видео — Whisper справляется с ускоренной речью, лекция проходит быстрее.

**Лимиты.** Если у модели закончился дневной бесплатный лимит Groq, расширение само переходит на запасную (у каждой модели свой лимит): распознавание — `whisper-large-v3` → `whisper-large-v3-turbo`, конспект — `gpt-oss-120b` → `gpt-oss-20b` → другие доступные.

## Режимы

| | Распознавание | Конспект | Цена |
|---|---|---|---|
| **По умолчанию** | Groq Whisper large-v3 | Groq GPT-OSS 120B (если её снимут — расширение само выберет доступную) | бесплатно в пределах лимитов Groq |
| **Офлайн** | Whisper прямо в браузере (WebGPU) | без ИИ или встроенный ИИ Chrome | бесплатно, звук никуда не уходит |
| **OpenAI** | gpt-4o-mini-transcribe | gpt-4o-mini | ≈ $0,2–0,4 за час видео |

Локальный режим рекомендуется на Mac с M1 и новее. Модель (по умолчанию whisper-small, ≈250 МБ) скачивается один раз, это можно сделать заранее в настройках.

Встроенный ИИ Chrome (Gemini Nano) работает экспериментально: нужен Chrome 138+, около 22 ГБ свободного места, а русский язык поддерживается не на всех версиях.

## Как это устроено

- `background.js` управляет записью, хранит сессии в `chrome.storage.local` и пишет конспект через LLM порциями (≈3500 символов).
- `offscreen.js` захватывает звук вкладки (`chrome.tabCapture`), возвращает его в динамики, переводит в 16 кГц моно, режет на фрагменты 12–28 с по паузам, пропускает тишину и отправляет фрагменты на распознавание. Типовые «галлюцинации» Whisper («Субтитры сделал DimaTorzok» и т. п.) отфильтровываются.
- `local-asr-worker.js` — сборка [transformers.js](https://github.com/huggingface/transformers.js) для локального Whisper (исходник в `src/`).
- `sidepanel.*` — боковая панель, `popup.*` — кнопка записи, `options.*` — настройки.

## Сборка из исходников

Нужно только если меняете `src/local-asr-worker.src.js`:

```bash
npm install
npm run build   # пересобирает extension/local-asr-worker.js и копирует wasm ONNX Runtime
npm run zip     # conspector.zip для загрузки в Chrome Web Store
```
