Конспектор — настройки

Быстрый старт (бесплатно):

  1. Зайдите на console.groq.com/keys (вход через Google), нажмите Create API Key и скопируйте ключ.
  2. Вставьте его в поле «Ключ Groq» ниже и нажмите «Сохранить».
  3. Откройте видео, нажмите значок Конспектора → ● Начать запись.

Распознавание речи

Модель скачивается один раз и хранится в браузере. На Mac с M1 и новее работает через видеокарту.

Конспект

3500 символов ≈ 3–4 минуты речи. Меньше — чаще обновления, но больше запросов.

Ключи API

Ключи хранятся только в этом браузере и отправляются только в Groq / OpenAI.
